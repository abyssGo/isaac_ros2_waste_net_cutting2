# 폐어망 공장 배경 적용 결과 (2026-10-09, RTX 3080)

이 폴더(`netclean_run_set_factory`)는 실행 세트 `netclean_run_set` 의 **복사본**이다. 원본 세트는 수정하지 않았다.
복사본에서 바꾼 실행 파일은 `scripts/run_standalone.sh` 의 기본 월드(→ `simulation_integration_v4_factory.usda`) 하나뿐이다.
원래 월드로 돌리려면 `NETCLEAN_USD=$PWD/sim/assets/project1/simulation_integration_v4.usd ./scripts/run_standalone.sh`.

## 1. 한 일

| 단계 | 내용 | 카메라 영상 영향 |
|---|---|---|
| 1. 시야 밖 장식 | 로봇 뒤 벽·기둥·랙(상자 적재), 측벽, 선별품 팔레트(PET/캔/부표 표지), 드럼통, 지게차, 카트, 보행 통로선, 안전 표지 | 없음(아래 2.1) |
| 2. 어망 뒤 차폐판 | 어망 뒤 x = −2.6 m 에 무광 회색 판 1장(폭 10 m × 높이 4.3 m). 그 뒤 원래 흰 벽을 끄고 공장 벽·지붕·조명·랙·수거 어망 적치장·라인 간판 배치 | 배경만 바뀜(아래 2.2) |

- 원본 월드 USD 는 그대로 두고, 장식은 별도 레이어 3개를 sublayer 로 얹었다(`sim/assets/factory/README.md`).
- 장식은 모두 시각 전용(충돌·강체·조인트 끔). 광원은 추가하지 않았다. 지붕·조명·로봇 뒤 벽은 그림자를 끄고 기존 조명을 그대로 유지했다.
- 에셋: Isaac Sim 5.1 공개 창고 소품(약 430 MB, 복사본에 포함 → 오프라인 실행). 수거 어망 더미는 팀 어망 메시를 물리 끄고 재사용. 한글 표지판 텍스처는 직접 생성.

사진: `renders/factory_overview.png`(로봇 쪽에서 본 라인), `renders/factory_robotside.png`(로봇 뒤 공장), `renders/factory_line.png`(정면).

## 2. 비전 영향 검증

### 2.1 자동 기하 검사 (`sim/assets/factory/visibility_check.txt`)
장식 단위 138개(1단계 63개 + 2단계 75개)의 바운딩 박스를 표본화해 두 카메라 시야(94.5°, 5 % 여유)와 광원(−X, 45° 하향) 그림자 경로를 검사했다.
1단계 월드 0건, 최종 월드 0건(차폐판 1장만 의도적으로 시야 안). 처음 배치에서 측벽 일부(x < 0)의 그림자가 먼 바닥 모서리에 닿는 것을 이 검사가 잡아내 2단계로 옮겼다.

### 2.2 같은 장면 정지 렌더 비교 (`renders/`, `vision_compare.txt`)
어망을 Station 1·2 에 놓고 두 카메라를 640×640 으로 렌더해 원본 월드와 비교(물리 정지, YOLO 는 팀 `best.pt`).

| 비교 | 화소 차이(평균) | YOLO (3종 신뢰도 / 박스 중심 이동) | Vision 2 3D 목표 차이 | 빈 화면 오검출 |
|---|---|---|---|---|
| 원본 vs 원본(+3 프레임) — 렌더러 자체 흔들림 | 0.9–1.5 | 동일 / 0 px | 0 mm | 0 |
| 원본 vs 1단계(시야 밖 장식) | 1.6 (빈 화면 0.5) | 동일 / ≤ 0.1 px | 최대 1.5 mm | 0 |
| 원본 vs 최종(차폐판) | 14.8 (배경 교체) | ±0.001 / ≤ 0.2 px | 최대 1.5 mm | 0 |

- 깊이 영상: 1단계는 원본과 완전히 같다(시야 안 기하 변화 없음).
- 1단계의 화소 차이는 어망 줄 가장자리에만 있고, 원본을 3 프레임 늦게 렌더한 차이와 크기가 같다(렌더러 흔들림 수준). 1단계 Station 1 에 신뢰도 0.163 의 오검출 박스 1개가 화면 모서리에 생겼으나 실행 기준(0.40/0.50) 미만.
- 차폐판 위치: 처음 x = −1.6 m 에 두었더니 윗레일 그림자가 판에 띠로 찍혔다(`renders/backdrop_position_shadow.png`). x = −2.6 m 로 물려 레일·물체 그림자가 원본처럼 바닥에 떨어지게 했다.
- 차폐판 밝기: albedo 0.35 와 0.70 모두 YOLO 결과가 같았고, 0.35(렌더 시 밝은 회색, 원래 흰 벽과 비슷한 밝기)를 채택.
- Vision 1 은 고정 어망 평면(0.59 m)을 쓰므로 깊이 영향 없음. Vision 2 는 5 m 이내 깊이를 쓰는데 차폐판(2.5 m)이 유효 깊이가 되지만, 목표 선택이 물체 표면 중앙값이라 결과가 바뀌지 않았다(위 표).

### 원인: 배경의 비전 영향이 아니라, 흡착컵이 페트병에 먼저 닿아 TCP 가 미끄러짐 (2026-10-10 측정으로 확정)
- 원본 월드 10·11차에서도 페트병 흡착 표면 거리는 **매번 2.70 cm**(허용 3 cm)였다. 여유가 3 mm 뿐이었다.
- 15차(원본 월드)에 흡착 판정 순간의 TCP·AABB 를 기록했다: 물체는 정지 위치 그대로였고, **로봇 TCP 가 명령 위치에서 페트병 6.6 cm, 캔 7.8 cm 옆으로 미끄러져 있었다**(부표는 0.2 cm).
  CONTACT 목표는 물체 중앙의 깊이(표면)인데 페트병은 가장 튀어나온 면이 그보다 8.5 mm 앞에 있어 흡착컵이 먼저 닿고, 강성이 낮은 1축(160)이 밀린다.
- 미끄러진 양은 시간에 따라 변한다. Robot 2 대기가 벽시계 `time.sleep` 이라, 장식으로 시뮬이 약 8 % 느려지면(실시간 비율 0.94 → 0.86) 판정 시점의 위치가 달라져
  2.70 → 3.06(1단계) → 3.38–3.94 cm(최종)로 커졌다. 처음 적었던 "페트병이 흔들린다" 는 추정은 틀렸다(물체는 움직이지 않았다).
